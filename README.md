# 🎬 **Theater Ticket Booking System**
### JSP • Servlet • JDBC • MySQL • MVC Architecture

🚀 A full-stack ticket booking web application where users can explore movies, pick seats, and book tickets — with an **Admin Portal** to manage movies.

</div>

---

## 🌟 Features

| User Features | Admin Features |
|--------------|----------------|
| Login / Register | Admin Login |
| View movie list | Add new movie |
| Seat selection (5×5 grid A1–E5) | Delete movie |
| Real-time booking lock system | Reset seat availability |
| Booking receipt | Promote user to admin |
| Booking history page | Manage posters |

## 📝 Project Overview

The system follows the **MVC architecture**:
- **Model** → Java classes (Movie, Seat, User…)
- **View** → JSP pages
- **Controller** → Servlets
- **Repository** → DAO Classes (SQL execution)

Uses **cookie-based login** instead of session to maintain user identity.
